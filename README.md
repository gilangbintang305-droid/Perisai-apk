# Perisai

Aplikasi keamanan perangkat (checklist, cek password, cek link, generator password).

## Cara mendapatkan APK
1. Buat repo baru di GitHub, unggah semua file ini (termasuk folder `.github`).
2. Buka tab **Actions**, jalankan **Build APK** (otomatis jalan tiap push ke `main`).
3. Setelah selesai (±5 menit), unduh **perisai-apk** dari bagian Artifacts, lalu ekstrak untuk mendapat `app-debug.apk`.
4. Pasang di HP (izinkan instal dari sumber ini).

APK ini berupa debug build. Untuk rilis ke Play Store, perlu tanda tangan (keystore).
